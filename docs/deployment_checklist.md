# Deployment Checklist

## Automatically verified

- [x] Secrets and private-path audit completed
- [x] Large files reviewed
- [x] Raw and processed datasets excluded from Git
- [x] Reproducible lightweight app data created
- [x] UK Open Government Licence attribution present
- [x] Direct Python dependencies pinned
- [x] Verified model available locally
- [x] Git LFS rule prepared for the verified model
- [x] App data available
- [x] Full local tests passing
- [x] Local app startup and prediction smoke-tested
- [x] Scientific claims audited
- [x] README reviewed
- [x] Five genuine local screenshots created

## Human release checks

- [ ] Visually review every final page on the author's own laptop and phone
- [ ] Approve the captured screenshots
- [ ] Create or select the public GitHub repository
- [ ] Confirm Git LFS is installed before adding the model
- [ ] Review the complete staged-file list
- [ ] Confirm the Git working tree is clean after the release commit
- [ ] Push the reviewed repository
- [ ] Deploy through the author's Streamlit account
- [ ] Smoke-test the public URL, including a real estimator submission
- [ ] Verify mobile rendering on a physical device
- [ ] Add final GitHub and Live Demo URLs to portfolio materials

No public repository or live deployment is claimed by this checklist.
