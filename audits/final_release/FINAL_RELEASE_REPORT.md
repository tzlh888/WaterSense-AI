   DO=94 mg/L、饱和度=10%、温度=18°C，无 DO 限值标记。

   不擅自改成 9.4 或其他值。该行贡献总平方误差 73.92%。

   两条身份冲突记录均缺失 DO，排除后再排除其余 2,588 条缺失真值。
   评估仅针对已测真值子集，不能假设缺失随机。

   低氧站点支持未达十站门槛。站点 Bootstrap 不能制造新站点证据；
