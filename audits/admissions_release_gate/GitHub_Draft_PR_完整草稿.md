## PR 描述

### 问题与本分支结果

平均误差较低的环境模型仍可能漏掉大部分罕见低氧观测。本分支整理可复核的
数据、预测、统计分析和失败证据，防止平均分数掩盖可靠性问题。
本轮最后门禁只审阅既有结果与贡献来源，没有新增科研训练、预测、调参或重复实验。

历史建模表包含 151,031 条观测、840 个站点，覆盖 1990–2024。
V3 使用 119,690 条开发观测、672 个站点及嵌套站点分组验证。
所选流程将低氧 MAE 从 3.3235 降至 2.3613 mg/L、Recall 从 0.1293 提高至
0.3641，同时整体 MAE 从 0.8797 升至 0.9516，FP 从 26 增至 219。
这支持完整流程的取舍，不单独证明权重的因果作用。

历史原始数据、清洗表和审计的精确哈希已恢复，固定 Phase4 历史重放在前轮
完成；计算可复现与外部泛化不同。EA 英格兰试点未通过测量兼容性和站点支持
门禁，没有 EA 模型性能结果。

2,590/6,080 条源记录缺少 DO（42.60%），结果仅针对有真值子集。

其余抽样的 [1,1] 不代表完美可靠。

这属于同监测体系的后来时期证据，不是跨地区确认、V3 权重策略的外部确认、
未来预测或部署验证。当地监测缺失与稀疏站点支持限制总体解释。
