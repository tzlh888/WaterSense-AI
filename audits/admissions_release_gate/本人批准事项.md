以下均未由 AI 代答，不以沉默或已有本地提交视为同意。

| 事项 | 本人需要给出的具体决定 | 当前状态 |
|---|---|---|
| 个人研究贡献 | 填写中文表；给出亲自决策、编码、核验和写作的具体证据 | BLOCKED：待本人确认 |
| 第一人称申请文字 | 每条 CV/口述确认、改为协作措辞或删除；核对作者姓名 | BLOCKED：待本人确认 |
| 运行前审阅 | 是否本人在 2025 运行前审阅过协议；未发生则不得如此陈述 | BLOCKED：待本人确认 |
| AI 使用披露 | 确认协作范围与目标院校要求；不声称未使用 AI | BLOCKED：待本人确认 |
| Git 身份 | 是否公开保留的本机邮箱/主机身份；未来提交使用何种公开身份 | BLOCKED：公开前待本人决定 |
| 数据与隐私 | 同意公开现有派生环境行、公开来源快照及其归属声明 | BLOCKED：待本人审阅 |

| 合并 main | 独立人类审阅、测试例外记录后，明确批准 merge commit | 未授权，不执行 |
| 部署、Release、论文发表或申请提交 | 分别确认渠道、内容、署名及是否正式提交 | 未授权，不执行 |

不要求再训练或继续调优来解除上述门禁。跨地区验证、异常值真实性、
目标缺失选择和稀疏事件站点属于公开时必须保留的科研局限。
